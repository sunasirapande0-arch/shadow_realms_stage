# Shadow Realms: Warrior's Awakening - Stage 2 prototype (Godot 4.2+)

Open `project.godot` in Godot 4.2 or newer and press Play (F5).
Everything is built from engine primitives in code: no external assets, no licences to track.

Desktop: WASD move, Shift sprint, Space jump, Q dodge/roll, LMB or J attack (3-hit combo),
V toggle first/third person, mouse wheel zoom, Esc frees the mouse.
Phone: left side = floating joystick, right side drag = look, buttons ATK/JUMP/ROLL/RUN/CAM.
